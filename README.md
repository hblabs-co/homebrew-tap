# hblabs Homebrew tap

```sh
brew install --cask hblabs-co/tap/freeroom
```

| Cask | What it is |
|---|---|
| `freeroom` | [Freeroom](https://github.com/hblabs-co/freeroom): free up disk space on macOS with an agent that understands what it's deleting. Menu bar app + `freeroom` CLI. |

The `freeroom` cask is published with the first signed and notarized release.
